# Linux System Monitor

Script en Bash para la supervision basica del estado operativo de un sistema Linux.

## Caracteristicas
* Muestra la fecha y hora de la auditoria.
* Consulta el consumo y disponibilidad de memoria RAM (`free -h`).

## Requisitos y Ejecucion
1. Clonar el repositorio:
   git clone https://github.com/oscarmaldonadosec-cmd/linux-sustem-monitor.git
2. Entrar a la carpeta:
   cd linux-system-monitor
3. Dar permisos de ejecucion:
   chmod +x monitor.sh
4. Ejecutar el script:
   ./monitor.sh
